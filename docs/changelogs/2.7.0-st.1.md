# ChatPlus Staff Tools 2.7.0-st.1

Based on ChatPlus 2.7.0. Everything from ChatPlus works and looks the same.

## Added
- Right-click a player's name in chat for a small menu: Lookup, Message, Note, Warn, Temp-ban, Unstuck, extra profile commands, and Copy name.
- A lookup screen that lists warnings, notes and active bans, with Remove and Unban buttons.
- A confirm screen for every command that changes something. It shows the exact command, and Send is disabled for the first half second.
- A Moderation section in the ChatPlus settings screen, and the `/mt` command.
- All server-specific behaviour comes from `config/chatplus/moderation/profile.json`. The bundled profile is empty.

## Fixed
- Translate: sentences no longer get double spaces.
- Translate: selected lines no longer pair with the wrong translation.
- Translate: translated text is added to chat on the client thread.
- Translate: an API error now pauses translation for 5 minutes instead of for the rest of the session.
- Translate: requests time out instead of hanging.
- From ChatPlus 2.8.0: memory leak in chat bar elements, crash guard when drawing chat lines, copy message formatting.
