# ChatPlus Staff Tools 2.7.0-st.2

Translator fixes. Nothing to set up: translation still uses the free Google endpoint, with no key or account.

## Ctrl+click translate
- No longer does nothing when Google reports a language the mod didn't know. Google uses its own codes for some languages (Hebrew is `iw`, Javanese `jw`), and short messages are often guessed as rare languages. The translation is shown anyway.
- A Ctrl+click on another message straight after a translation now works. The 2-second wait only applies to clicking the same message twice.
- Says why it couldn't translate (paused, can't reach Google, Google error, nothing to translate) instead of doing nothing.
- A Google error now pauses translation for 30 seconds instead of 5 minutes. Only rate limiting still pauses for 5 minutes, and having no connection pauses nothing.
- No longer also runs the clicked text's own action, such as opening a link or filling in a `/msg` command.
- A long message that wraps over several selected lines is translated once, not once per line.
- More accurate: player names and rank tags (`[Admin] Steve: `, `<Steve> `, `Steve » `, `Steve -> me: `) are no longer sent to Google. Only the message is translated, and the name is put back in front unchanged. Your translator regexes are tried first, for chat formats this doesn't recognise.
- ChatPlus's own timestamps and repeat counters are no longer sent to Google.
- Selected messages are sent one per line instead of joined with `§`, Minecraft's colour-code character, which Google sometimes dropped or moved.

## Translate To: Auto Detect
- "Auto Detect", the default, now means the language Minecraft is set to, falling back to English. Before, the mod sent "auto" to Google as the language to translate into.

## Speak mode (Ctrl+T)
- Typed commands are sent as typed. Before, `/home` was sent as Google's translation of it, and speak mode stays on after chat closes.
- A command prefix such as `/msg Steve` keeps its space, so messages no longer go out as `/msg Stevehola` (the same fix as ChatPlus 2.10.0).
- When Google can't be reached, nothing is sent, the reason is shown, and clicking it puts the text back in the input box. Before, the message was lost. With both languages set the same, the text is sent as typed instead of being dropped.

## Staff tools
- Lookup: a reply that shows the player under another name (such as a nickname) now fills the lookup screen. Lookups are forgotten when you change server.

## From ChatPlus 2.10.0
- An error in one chat feature no longer stops the others from running (`71084fa`).
