# ChatPlus Staff Tools 2.7.0-st.4

## Player list
- Nicknames: each player's nickname from the tab list is shown next to their username, and the search box finds players by nickname too. The last known nickname is saved with the list.
- Seen button: offline players have a **Seen** button. It sends the profile's `seen` command for that player, only when clicked, and the server's reply updates their last-seen time. The reply is shown under the list. Seen in the name menu updates the list too.
- New profile options: `chat.nickFromTab` (how to find the nickname in a tab list name) and a `seen` group in the `seen` command's `reply` patterns (the date and time of the last visit).

## Other
- The offline self-test skips its translate checks while Google is rate limiting, instead of failing them.
